# Compact-native streaming thought process & background task status

Status: implemented
Translation: current

[中文](2026-11-21-streaming-thought-preview.zh.md)

## Abstract

Agents that narrate work primarily through `agent_thought_chunk` (notably Antigravity CLI) leave running turns showing only a collapsed tool-count header, and expanding a finished turn previously required clicking through two nested layers ("Worked for X" → collapsed activity group). In addition, turns whose main reply finished while background tasks remain active (`running + backgroundTaskState: background`) previously displayed an un-timed orphan "Thinking" line and active spinners. This fork adds: (1) an opt-in, render-only Option C compact-native fixed two-tier streaming header (status + persistent tool counts + duration on Row 1; full latest valid thought paragraph on Row 2) and flat single-level process directory behind `streamingThoughtPreviewFeatureEnabledAtom`, and (2) always-on native background task status indicators across the sidebar, tab bar, and post-answer chat stream. Live daemon chunk cadence and native iOS rendering remain outside this change.

## Decision

Split the change cleanly into an opt-in presentation upgrade (`streaming-thought-preview.ts`, `compact-native-directory.ts`, `compact-native-directory-row.tsx`) and always-on native background presence indicators (`background-task-status-row.tsx`, `working-status-mark.tsx`, `session-list-rows.ts`, `sidebar-row-shared.tsx`, `session-tab-bar.tsx`), with minimal row wiring in `view.tsx`.

- **Prerequisite upstream sync.** Cherry-picked upstream #2896 (`1c2a979cb`, keeping live status inside the streaming row's measurement boundary) first so live chrome and the compact live header share the same virtual-row measurement boundary and minimize future merge conflicts in `view.tsx`.
- **Opt-in Option C fixed two-tier streaming header (uniform across providers).** Behind `streamingThoughtPreviewFeatureEnabledAtom` (OFF preserves 100% upstream behavior), Row 1 and Row 2 never swap roles between thinking and tool execution:
  - **Row 1 (`13px`, single-line `nowrap`, outer `.agent-shimmer` wrapper while live, disabled in Low-stimulus mode):** always holds status + completed/background tool counts + elapsed duration, never thought prose. Shows `Thinking (<duration>)` or `Thinking · <toolCounts> (<duration>)` while thinking (uniformly using `sessions.compactProcess.thinking` even for placeholder-only starts so the verb never flickers between `Thinking…` and `Thinking`), and `Running <target> (<duration>)` or `Running <target> · <toolCounts> (<duration>)` while a non-background tool is `in_progress`. `summarizeCompactTools(entries)` stays active throughout `isLive` so tool counts never disappear or jump rows. Status verbs and `(<duration>)` pin `flexShrink: 0`; `<target>` shrinks (`flex: 0 2 auto`) ahead of `<toolCounts>` (`flex: 0 1 auto`) with single-line ellipsis so 390px viewports never squeeze `(<duration>)` out.
  - **Row 2 (`12px` muted `secondaryLabel`, `white-space: pre-line`, `overflow-wrap: anywhere`, no `line-clamp`):** rendered only when `isLive && !expanded` and a valid thought paragraph exists (after stripping Antigravity's placeholder). Displays the full latest valid thought paragraph—preserving multiple sentences, natural line breaks, and long paths/URLs without 140-char, 260-char, or 1024-char per-line truncation—and retains the last valid paragraph across tool calls, placeholders, and unclosed `**` headings. Automatically disappears when expanded or when the turn settles (`Worked for <duration>` on desktop; `Finished working` on mobile, where the footer owns duration).
- **Single-level expanded process directory.** Clicking the live header or the finished native `Worked for <duration>` header (without token statistics or extra chrome) opens flat sibling directory rows directly, removing the nested `ActivityGroupHeader` click. Each valid thought starts collapsed as a one-line first-sentence excerpt with Antigravity's placeholder stripped (with a right-aligned `Expand all thoughts / Collapse all thoughts` button when >1 valid thoughts exist); consecutive completed non-background `read` tools cluster into one expandable row keyed by the first tool's stable identity (preserving expansion as new reads stream in); standalone `read` and `edit` rows with outputs/diffs retain an independent clickable file-name button to open the source file while row clicks toggle details; other tools expand their detail sheet on whole-row click with no "View output" badge, and commands with persisted `tool_call.backgroundTaskId` show a neutral historical `BG` micro-badge independent of live presence. Completed-turn `#2353` folding, per-session expand memory (`sessionId` + `messageId`, isolating forked turns), placeholder-aligned thought search indexing (`stripAgyPlaceholderFromMarkdown`), and Low-stimulus rules remain intact.
- **Safe extraction, virtual-list measurement, and anti-flicker.** Reuses the single O(n) forward scan in `streaming-thought-preview.ts` (continuous cross-paragraph HTML comment tracking, unclosed leading `**` checks, placeholder stripping, and 1500 ms / 4000 ms Low-stimulus hold throttling). Row 2 uses `extractLatestThoughtParagraphFromText` / `extractLatestCompactThoughtParagraph`, collecting all valid lines of the latest valid paragraph bounded by `STREAMING_THOUGHT_PREVIEW_MAX_CLEANED_CHARS` (8,192 chars) and `STREAMING_THOUGHT_PREVIEW_MAX_CLEANED_LINES` (32 lines), while expanded directory rows retain dot-safe first-sentence extraction (`view.tsx`, `v2.1` preserved). Option C reads synced history exclusively and never reads presence, avoiding upstream #807 heartbeat congestion. Dynamic Row 2 growth/shrinkage (including async throttled updates) propagates through `EngineConversationScroller`'s row `ResizeObserver` -> `ScrollController.onRowsResized` (`flushSync`) to update following row offsets (`subagent_tasks`, `footer`) and keep `follow` mode sticky; `ScrollController.preserveDisclosure` marks the toggled header row dirty so expanding a tall live header (shrinking Row 2 away) re-measures in the same click commit before mobile reveal checks run.
- **Always-on native background task status.** Consumes Phase 1 `liveSessionStatus` (`backgroundTaskState: 'background' | 'running'`, `backgroundTaskCount`) independent of the experimental switch while keeping `phase` strictly `'finalizing'` for rolling-upgrade compatibility with baseline LAN clients:
  - Sidebar rows, folded group marks (`failed > waiting > working > background > sending > unread`), and `SessionTabBar` show a calm breathing ring (`BackgroundStatusMark`, static in Low-stimulus mode) during silent background waiting, returning to the active working mark on wakeup pulses (`backgroundTaskState: 'running'`).
  - Below a finished turn's final answer, `BackgroundTaskStatusRow` replaces any orphan un-timed "Thinking" line with a pure-typography, non-expandable single row aligned to `conversation.railInset` (zero card/border) reporting only the authoritative aggregate presence signal: calm breathing dot + `<count> background tasks running` (or generic `Background task running`) during waiting, and shimmered `Handling background task` during wakeup pulses, without attributing a possibly stale historical command as currently running.
  - Minimalism boundary: `ChatComposer` (default placeholder, send arrow `↑`) and the right side of `SessionTabBar` stay completely unchanged, with no instructional copy or presence/polling details.

## Alternatives

- **Swapping thought excerpts and tool counts between Row 1 and Row 2 across thinking/tool phases:** Causes vertical eye-jump every time the agent starts or finishes a tool call, and clipping Row 2 to a single truncated line hides the actual reasoning being narrated.
- **Keeping the two-layer "Worked for X → ActivityGroupHeader" nesting:** Forces two clicks to inspect reasoning or tool outputs after a turn ends and adds redundant header chrome.
- **Auto-expanding thought groups while streaming or rewriting thoughts as commentary:** Causes scroll churn/flicker mid-turn or leaks reasoning into `lody_session_history` and breaks `#2353` folding.
- **Adding helper banners to `ChatComposer` or `SessionTabBar` during background tasks:** Adds visual noise for a state the user already reads from the calm breathing mark and bottom status line.
